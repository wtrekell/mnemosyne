# qmd

Local, on-device search engine for markdown files with hybrid BM25/vector search and LLM re-ranking, available as a CLI and an MCP server (github.com/tobi/qmd). Suggested in [[llm-wiki]] as the upgrade when the index file in [[index-and-log]] no longer suffices. A naive self-built search script is the stated alternative.
